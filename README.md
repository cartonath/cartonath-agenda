# CartoNath Agenda v0.4 RC2

Esta é uma Release Candidate, feita para teste final no iPhone antes de uso real.

## Servir localmente
`python3 -m http.server 8000`

## Testes
`node tests.js`

## iPhone
A PWA precisa de HTTPS. Publique a pasta em um host estático e abra o endereço no Safari.
Depois: Compartilhar > Adicionar à Tela de Início.

## Importante
Não use dados reais antes de completar o checklist de teste físico descrito em QA_CHECKLIST.md.
